로렐라이 홈페이지 콘텐츠 관리 시스템

저장 상태: 확인 중...
용량: -

1. 콘텐츠 수정

  1. 왼쪽 메뉴에서 수정할 영역 선택
  2. 텍스트 필드 입력
  3. 상단 전체 저장 버튼 클릭
  4. 사이트 미리보기로 결과 확인

2. 이미지 업로드

  1. 왼쪽 이미지 업로드 클릭
  2. 각 카드에서 업로드 버튼
  3. 이미지 선택 후 미리보기 확인
  4. 전체 저장으로 반영

⚠ 파일당 2MB 이하 권장. 합계 5MB 한도.

3. 백업 / 이전

  1. JSON 내보내기: 모든 콘텐츠를 파일로
  2. JSON 불러오기: 백업 복원 또는 다른 PC로 이전

⚠ 초기화

모든 입력 내용을 지우고 처음 상태로 되돌립니다.
