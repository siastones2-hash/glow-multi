처음 주문하시는 분들이 가장 많이 묻는 질문을 정리했습니다.

회원가입 → 충전 → 서비스 선택 → 링크 입력 → 수량 입력 → 주문하기 순서로 진행됩니다. 대부분 작업은 24시간 이내 자동 반영됩니다.
팔로워는 프로필/채널 링크, 좋아요·조회수는 게시물/영상 링크를 넣어주세요. 비공개 계정이나 삭제된 링크는 작업이 진행되지 않을 수 있습니다.
작업이 시작되기 전에는 일부 취소가 가능하지만, 진행된 주문은 취소·변경이 어려울 수 있습니다. 링크/수량을 꼭 확인 후 주문해주세요.
서비스별 시작 속도는 다르지만 보통 주문 직후부터 순차 반영됩니다. 급격한 변동보다 자연스러운 증감 형태로 처리됩니다.
