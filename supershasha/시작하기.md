# 🚀 실제로 가동하기 (둘 중 하나만 하면 끝)

코드는 100% 완성돼 있어요. 아래 **A(가장 쉬움)** 또는 **B**, 하나만 하면 실제로 작동합니다.
실행하는 순간 모어댄에 연결되어 **실제 상품 6,000여 개가 자동으로 들어오고**, 주문도 실제로 나갑니다.

---

## A. 영구 사이트로 (추천) — Render 무료 배포, 약 5분

인터넷 주소(URL)가 생겨서 어디서든 접속돼요. 컴퓨터 안 켜놔도 됩니다.

1. **GitHub에 코드 올리기**
   - github.com 로그인 → 우상단 ＋ → New repository → 이름 `supershasha` → **Private** → Create
   - 만들어진 화면에서 "uploading an existing file" 클릭 → 이 폴더 안 파일 전부 드래그 → Commit
   - (`.env`는 올리지 마세요. 키가 들어있어요. `.gitignore`가 자동으로 막아줍니다.)

2. **Render에서 배포**
   - render.com 가입(GitHub로 로그인 가능) → New ＋ → **Blueprint**
   - 방금 만든 `supershasha` 저장소 선택 → Apply
   - `render.yaml`을 자동으로 읽어 설정돼요. 중간에 두 값만 입력:
     - `MORETHAN_API_KEY` → `64b5ff6ae2cf3d9ed337c9af7fc9e2a1`
     - `ADMIN_PASSWORD` → 원하는 관리자 비밀번호
   - Create / Deploy → 2~3분 후 `https://supershasha.onrender.com` 같은 주소 완성

3. **접속**
   - 본사: `https://...onrender.com`
   - 지인 사이트: `https://...onrender.com/?tenant=nine`
   - 관리자 로그인: `leestones` / (위에서 정한 비밀번호)

---

## B. 내 컴퓨터에서 바로 (테스트용)

1. **Node.js 설치** (한 번만): https://nodejs.org → LTS 버튼 → 설치
2. **더블클릭**:
   - 윈도우: `실행_Windows.bat`
   - 맥: `실행_Mac.command` (처음엔 우클릭 → 열기)
3. 자동으로 설치되고 브라우저에 `http://localhost:3000`이 열립니다.
   - 관리자: `leestones` / `1234` (→ `.env`에서 변경 권장)
   - 끄려면 검은 창을 닫으면 됩니다. 컴퓨터를 꺼도 사이트가 닫혀요(테스트용).

---

## ✅ 연결 확인 방법

관리자로 로그인 → **대시보드** → "공급 잔액"에 모어댄 잔액($)이 보이면 = **모어댄 실연동 성공**.
상품 목록도 모어댄 실제 6,000여 개로 채워집니다.
(`.env`의 `KOREA_ONLY=true`로 바꾸면 한국 타겟 상품만 걸러서 보여줘요.)

## 자주 막히는 곳

- **상품이 25개만 보임** → 아직 서버 미연결(미리보기)이거나 모어댄 응답 실패. A 또는 B로 실제 실행하면 전체가 들어옵니다.
- **로그인 안 됨** → 관리자 아이디 `leestones`, 비밀번호는 `.env`/Render에 넣은 값.
- **모어댄 잔액이 안 보임** → API 키 오타 확인. Render는 환경변수 `MORETHAN_API_KEY` 재확인 후 Manual Deploy.
- **비밀번호 변경** → Render 환경변수 `ADMIN_PASSWORD` 수정 후 재배포, 로컬은 `.env` 수정 후 재실행.
