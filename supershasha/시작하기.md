# 🚀 슈퍼샤샤 가동하기

코드는 API 연결 전까지 **미리보기 모드**로 동작합니다.  
`.env`에 `MORETHAN_API_KEY`를 넣기 **전** 아래 체크리스트를 먼저 확인하세요.

→ **`API-연결전-체크리스트.md`** 참고

---

## A. 영구 사이트 (Render) — 약 5분

1. **GitHub Private** 저장소에 `supershasha` 폴더 업로드 (`.env`는 올리지 않음)
2. **Render** → New → **Blueprint** → 저장소 선택 → Apply
3. 환경변수 입력:
   - `MORETHAN_API_KEY` → 공급사에서 발급받은 키 (연결 준비되면)
   - `ADMIN_PASSWORD` → 강한 비밀번호
4. 배포 후 `https://supershasha.onrender.com` 접속

**접속 URL**
- 본사: `/?tenant=master`
- 대리점: `/?tenant=nine`
- 슈퍼샤샤(숨김): `/?tenant=sh4-op-internal` · `leestones` / (설정한 비번)

---

## B. 로컬 테스트

1. Node.js LTS 설치: https://nodejs.org
2. 맥: **`실행_Mac.command`** 더블클릭 (또는 `npm install && npm start`)
3. 브라우저: `http://localhost:3000/?tenant=master`

---

## ✅ API 연결 확인 (키 입력 후)

1. 관리자 로그인 → **관리자 → 개요**
2. **공급 잔액($)** 이 보이면 실연동 성공
3. 상단 노란 **미리보기** 배너가 사라져야 함
4. 소액 테스트 주문 → 주문번호 확인 → 새로고침으로 상태 동기화

> 상품은 공급사 전체가 아니라 **큐레이션된 인기 상품** (~100~200개)만 노출됩니다.  
> `KOREA_ONLY=true` 로 한국 타겟 상품만 필터 가능.

---

## 자주 막히는 곳

| 증상 | 원인 |
|------|------|
| 상단 "미리보기 모드" 배너 | API 키 없음 — 정상 (연결 전) |
| 상품 25~40개만 | 미리보기 샘플 또는 큐레이션 결과 |
| "공급사 연결 실패" 배너 | 키 오타·네트워크·공급사 장애 |
| 로그인 안 됨 | `?tenant=` 와 계정 종류 확인 |
| Render 데이터 초기화 | 무료 플랜 재배포 시 `data/db.json` 삭제됨 |
