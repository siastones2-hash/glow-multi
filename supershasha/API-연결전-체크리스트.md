# API 연결 전 체크리스트

공급사 API(`MORETHAN_API_KEY`)를 넣기 **전** 확인하세요.

## 1. 보안

- [ ] `.env`의 `ADMIN_PASSWORD` 변경 (기본 `1234` 금지)
- [ ] `SESSION_SECRET` 랜덤 문자열로 변경
- [ ] `.env`가 Git에 올라가지 않았는지 확인
- [ ] 슈퍼샤샤 URL(`?tenant=sh4-op-internal`)을 본사·대리점에 공유하지 않음

## 2. 멀티테넌트·마진

- [ ] 본사 `master` 로그인 → **내 사이트**에서 마진·환율(FX) 저장
- [ ] 슈퍼샤샤 → **대리점 등록**으로 대리점 + 관리자 계정 생성
- [ ] 대리점 `?tenant=slug` 접속·로그인·주문 화면 확인
- [ ] 크레딧 요청: 대리점→본사, 본사→슈퍼샤샤 흐름 테스트 (미리보기 모드)

## 3. 손님 화면 (4개국어)

- [ ] 🇰🇷🇨🇳🇻🇳🇹🇭 국기 클릭 → 로그인·대시보드·주문·충전 번역 확인
- [ ] 회원가입·주문 모달·주문내역 상태 표시

## 4. 관리자

- [ ] 충전 요청 → 승인/거절
- [ ] 회원 잔액 ± 조정
- [ ] 서비스 관리에서 마진 % 저장
- [ ] (선택) 텔레그램 봇·채팅 ID 설정

## 5. 미리보기 모드 확인

- [ ] API 키 **없이** 실행 시 상단 **미리보기** 배너 표시
- [ ] 샘플 상품으로 주문 UI·크레딧 차감 흐름 테스트 (실제 공급 주문은 나가지 않음)

## 6. API 연결 당일

- [ ] `.env` 또는 Render에 `MORETHAN_API_KEY` 입력
- [ ] 공급사 USD 잔액 충전
- [ ] 재시작/재배포 후 **공급 잔액($)** 표시 확인
- [ ] 최소 금액 테스트 주문 1건 → `providerOrderId` 확인
- [ ] 주문내역 ↻ 새로고침으로 상태 동기화

## 7. 배포 후 (운영)

- [ ] Render 무료: `data/db.json` 휘발 → 장기 운영 시 DB 전환 검토
- [ ] 도메인 연결 (선택)
- [ ] 기본 시드 비번(`master1234`, `nine1234`) 변경 또는 폐기

---

**연결 변수**

| 변수 | 설명 |
|------|------|
| `MORETHAN_API_KEY` | 공급사 API 키 |
| `MORETHAN_API_URL` | 기본 `https://morethanpanel.com/api/v2` |
| `FX_KRW` | USD→KRW (본사별 FX는 UI에서 덮어씀) |
| `KOREA_ONLY` | `true` 시 한국 키워드 상품만 |
